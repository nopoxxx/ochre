~/docs/about

ochre

Оболочка рабочего стола для композитора niri на Quickshell, целиком в стиле терминала: панель — строка shell-приглашения, меню — fzf, настройки — menuconfig, уведомления — строки лога, блокировка — getty. Девять палитр (по умолчанию Gruvbox dark hard), тёмные и светлые, шрифт Terminess (Terminus). Для Arch Linux и производных.

Раньше назывался nopox-shell. Обновление переносит всё само: настройки — в ~/.config/ochre/, конфиг niri — в ~/.config/niri/ochre/ вместе с include в config.kdl. Greeter под старым именем переустановите: Mod+S → system/ → обновить greeter.

user@ochre ~/ws/{1,[2]} [1] ❯ kitty # ~/projects [‹ 󰙯 󰓓] · cpu ▂▃▅▇ 4% · mem 1.7G · vol 40% · upd 2 · log 0 · ru · 21:58
  • панель из 17 модулей по зонам left / center / right, TUI-попапы по клику;
  • меню Mod+D для действий: программы, обои, пакеты pacman/AUR, питание;
  • настройки Mod+S в стиле menuconfig с поиском — без правки конфигов руками;
  • окна мониторов, биндов и обоев (wallhaven.cc);
  • темы: Gruvbox, Catppuccin, Rosé Pine, Tokyo Night, Everforest, Kanagawa, Solarized, Nord, Dracula и Wallpaper (палитра из обоев через matugen) — shell, niri, GTK, Qt, btop, терминал и greeter в одной палитре;
  • блокировка и greeter как getty, уведомления как лог, обновление shell одним кликом.
~/docs/install/

Установка

Arch Linux и производные (CachyOS, EndeavourOS, …), от обычного пользователя:

❯ bash <(curl -fsSL https://raw.githubusercontent.com/nopoxxx/ochre/main/install.sh)

Установщик сначала задаёт вопросы, показывает итог и только потом ставит:

выборварианты
терминалkitty, alacritty, ghostty, foot — конфиг с Terminess, цвета — из темы shell, Mod+Return
оболочкаzsh (подсказки и подсветка), fish, bash — приглашение как панель: user@host ~/путь ❯, красный ❯ после ошибки
браузерHelium, Firefox, Zen, Chromium, Brave, Vivaldi — станет браузером по умолчанию, Mod+Shift+B
файлыThunar, Nautilus, Dolphin, Nemo или yazi в терминале, Mod+E
программыпо группам: медиа, общение, графика, работа и код, игры, утилиты
Discordкак есть, с Vencord, с BetterDiscord или Vesktop вместо него

Нужен niri 25.11 или новее — установщик проверит и предложит обновить. Программы из AUR ставятся готовыми сборками из chaotic-aur (установщик предложит подключить его) — без компиляции, поэтому быстро; чего там нет — собирается из AUR. paru тоже ставится — им пользуется сам shell (обновления, +пакет в меню). Дальше — клон shell в ~/.config/quickshell, конфиг niri (или два include к вашему) и, по желанию, greeter. Всё, что заменяется, остаётся рядом как *.bak-<дата>.

флаги

флагчто делает
--yesбез вопросов, всё по умолчанию; pacman и paru получают --noconfirm
--terminal --shell --browser --filesвыбор без вопроса, например --terminal foot
--apps mpv,discord,steamпрограммы (none — никаких)
--discord-mod vencordnone, vencord, betterdiscord, vesktop
--keep-niri-configне заменять ваш config.kdl, только дописать include
--no-greeterне ставить greeter
--no-steam-notifyне ставить Millennium и плагин уведомлений Steam
--no-chaoticне подключать chaotic-aur: программы из AUR соберутся из исходников (дольше)
--branch <ветка>другая ветка репозитория
вручную 
❯ sudo pacman -S --needed niri quickshell xwayland-satellite kitty git networkmanager pipewire \
    pipewire-pulse wireplumber upower pacman-contrib libnotify polkit-gnome ttf-terminus-nerd paru wl-clipboard \
    qt6ct adw-gtk-theme xdg-desktop-portal-gnome
❯ git clone https://github.com/nopoxxx/ochre ~/.config/quickshell

Затем подключите shell к niri — см. extras/niri.kdl.

пакетом

Вместо git-клона shell можно поставить пакетом ochre-git: файлы — в /usr/share/ochre, обновления — вместе с системой. В AUR его пока нет, собирается из репозитория:

❯ git clone https://github.com/nopoxxx/ochre && cd ochre/extras/aur/ochre-git && makepkg -si
❯ ochre setup      # то же, что установщик: программы, конфиг niri, терминал, оболочка, greeter

Команда ochre: без аргументов — запустить shell, ochre ipc … — IPC, ochre restart — перезапуск, ochre greeter — экран входа. Обновлённый пакет shell подхватывает не на лету, а после перезапуска — о нём придёт уведомление с кнопкой. Индикатора ochre ↑ у пакета нет: обновления ставит пакетный менеджер.

~/docs/menu

Меню

Mod+D — меню действий в духе omarchy с нечётким поиском, Mod+Space — сразу программы. Разделы ведут себя как каталоги: ↵ или → — войти, Esc или ← — на уровень выше. Набор в корне ищет сразу по всему меню: программы, открытые окна и вложенные действия (firefox, update, settings, reboot). Часто запускаемые программы стоят выше остальных — и в apps/, и в поиске. logout, reboot и poweroff просят второе ↵.

~/
❯ █ ▌ apps/ запуск программ (Mod+Space) wallpaper обои; Tab — wallhaven settings все настройки, мониторы, сеть, звук system/ питание и сессия about о системе: fastfetch
  • system/ — lock, suspend, logout, reboot, poweroff;
  • help — главные клавиши и подсказки (то же окно показывается один раз при первом запуске);

Остальное — не разделами, а префиксом в начале запроса в корне:

  • > команда — выполнить в плавающем терминале, окно остаётся после команды: > htop;
  • @имя — открытые окна niri, недавние сверху; ↵ — перейти к окну;
  • /имя — нечёткий поиск файлов и папок через fd (по умолчанию в ~), ↵ — открыть;
  • ? запрос — поиск в браузере: DuckDuckGo, Google, Startpage, Brave или свой адрес с %s;
  • :имя — эмодзи по английскому имени (:thumbs), ↵ — в буфер; недавние сверху;
  • +пакет — установить: пакеты pacman и первой строкой поиск в AUR через paru; просто + — update (paru -Syu);
  • -пакет — удалить установленный (pacman -Rns);
  • % — таймер: без срока — 5, 10, 15, 25, 45 минут, час и stop; любой срок — %25m чай, %1h30m, %5:00, %90s (просто число — минуты). Идёт на панели: timer 24:59 чай, клик — пауза, правый — стоп, колёсико — ±1 минута; переживает перезапуск shell;
  • = и выражение — калькулятор: =2^10, =(1,5+2)*3, =sqrt(2); ↵ копирует ответ. Есть + - * / % ^, скобки, sqrt abs round floor ceil ln log sin cos tan, pi, e;
  • !вопрос — Claude Code в обычном окне терминала из ~; просто ! — new (новая сессия) и continue (продолжить последнюю). Команду можно сменить в настройках;
  • префиксы меняются в settings → вид → меню (например $ вместо >); пустой — выключен;
  • всё настраиваемое — не в меню, а в окне настроек (settings).
~/docs/home

Меню home

Клик по user@host на панели или Mod+A. Вид — home/ → меню → вид: control — центр управления под панелью (плитки, ползунки, медиа; wi-fi и bluetooth открываются по › на плитке), column — колонка у края во всю высоту, dashboard — три колонки посередине экрана, classic — прежний вид строками. В первых трёх секции — карточки, клик по заголовку их сворачивает. Всё управляется и мышью, и с клавиатуры: ↑↓ — элементы и секции, ←→ — внутри строки или значение, ↵ — действие, Tab — следующая секция, Esc — закрыть.

Mod+S → home/: какие секции показывать и в каком порядке (←→ — показать / скрыть, Shift+↑↓ — порядок), край экрана и ширина, город и единицы погоды (пустой город — по IP), ночной режим, запись экрана. Секции без устройства — Wi-Fi на десктопе, bluetooth без адаптера, батарея — не видны.

ночной режим

Тёплые цвета экрана через gammastep: переключатель ночь в меню, температура — в настройках. «По закату» включает его только от заката до рассвета в городе погоды.

запись экрана

Mod+Alt+R, кнопка в меню или qs ipc call record region / screen: область выделяется мышью (slurp), экран — монитор с фокусом. Звук — нет / системный / микрофон. Пока идёт запись, на панели ● REC — клик останавливает; файл — в ~/Videos/Screencasts, уведомление открывает папку.

индикатор громкости и яркости

При изменении громкости или яркости — клавишами, колёсиком, из других программ — внизу экрана появляется полоска vol ▕████████░░░░▏ 62%. Выключить или перенести — look/ → индикаторы.

~/docs/settings/

Настройки

Mod+S — большое окно: разделы слева, настройки карточками справа, у каждой — свой элемент: тумблер, кнопки вариантов, цвета, ползунок (можно тянуть), поле, кнопка. Мышью значение меняется сразу, ↺ — вернуть по умолчанию. Модули панели и секции home перетаскиваются мышью между зонами и внутри них. С клавиатуры — как в menuconfig: ←→ (или Space) — выбрать значение: видно было → ‹ станет ›; ↵ — применить, Esc или уход со строки — отменить. r — вернуть по умолчанию (тоже через ↵), / — поиск по всем настройкам, Tab — разделы. Изменённые значения помечены *.

system/мониторы, сеть, звук, приложения, конфиги, обновления shell

Анимация меню Mod+D, меню home и уведомлений выбирается отдельно: slide — выезжает, fade — проявляется, pop — вырастает из центра, unfold — разворачивается сверху вниз, type — печатается по символу: перед курсором █ бегут случайные знаки, за ним проступает окно; none — без анимации. Закрытие играет ту же анимацию в обратную сторону. Общая скорость — look/ → анимации (2 — вдвое быстрее, 0.5 — вдвое медленнее), у окон niri своё замедление в windows/.

Окна, открытые из настроек (мониторы, бинды, обои), по Esc возвращают в них.

~/docs/settings/monitors

Мониторы

system/ → мониторы: карта расположения, режим и частота, масштаб, поворот, расположение относительно другого монитора (справа от DP-1 и т.п.), VRR и основной монитор.

Любое изменение ждёт подтверждения y 15 секунд — иначе (или n / Esc) всё возвращается как было. Выключить последний работающий монитор нельзя.

~/docs/settings/binds

Бинды

input/ → бинды: все сочетания niri и ochre с поиском — изменить, добавить, отключить, вернуть. Сочетание можно нажать или ввести текстом; перед применением конфиг проверяется niri validate, и если не прошёл — изменение откатывается.

Без запроса список разбит на группы: ochre, программы, окна, фокус, перемещение, размеры, столы, мониторы, звук и медиа… Своя группа — подпись вида Игры: Steam (от двух биндов с одной приставкой).

Бинды собираются из трёх слоёв, следующий перекрывает предыдущий:

слойфайлкто пишет
1. ochre~/.config/niri/ochre/binds.kdlshell, из настроек (терминал, браузер…)
2. ваши~/.config/niri/config.kdlвы, руками
3. из окна биндов~/.config/niri/ochre/keys.kdlshell, из окна биндов

мьют микрофона и звука

В input/ → клавиши — строки мьют микрофона и мьют звука (наушники или колонки — устройство вывода по умолчанию). ↵ на строке и нажмите сочетание; ⇥ — ввести текстом (если сочетание уже занято niri, нажать его окну не получится), ⌫ — убрать. Работают и на экране блокировки; если сочетание занято другим биндом, подсказка внизу об этом скажет.

Файлы в ~/.config/niri/ochre/ перезаписываются при каждом запуске shell — ручные правки там пропадут. Свои бинды задавайте в окне биндов или в своём config.kdl.

~/docs/settings/wallpapers

Обои

Mod+Shift+W: сетка превью локальной коллекции ~/Pictures/Wallpapers/, Tab — поиск на wallhaven.cc с бесконечной прокруткой; выбранное скачивается в коллекцию. Режимы заполнения fill / fit / stretch.

Смена обоев — переходом (look/ → обои → переход): type — новые обои печатаются строками с курсором цвета акцента, blocks — проступают клетками, scan — развёрткой сверху вниз, fade, none или random. Скорость — вместе с остальными анимациями shell.

Первыми в сетке — фирменные обои ochre: horizon, sundown, field, tty. Первые три нарисованы под каждый акцент: пока они стоят, смена акцента в look/ меняет и их. При первом запуске стоит horizon.

~/docs/settings/apps

Приложения по умолчанию

system/ → приложения:

  • терминал — для Mod+Return и окон, которые открывает shell (обновления, nmtui…);
  • файловый менеджер — для Mod+E;
  • оболочка — zsh / fish / bash: откроется терминал с chsh (спросит пароль), действует с нового входа; нет пакета — поставит;
  • браузер — станет браузером по умолчанию и откроется по Mod+Shift+B; нет пакета — поставит через paru.

Оболочка и браузер берутся из системы: если отменить chsh, настройка сама вернётся к тому, что стоит на самом деле.

~/docs/shot

Скриншоты

Mod+Shift+S или Print: экраны замирают — тяните область, клик или Space — весь экран, w — окно (кликните по нему; снимается целиком, даже если не помещается на экране). Дальше — разметка и экспорт.

~/shot/ 1200×800
r rect e ellipse l line a arrow p pen m marker t text n step b blur x pixelцвет [█] █ █ █ █ █ █ █ толщина ‹ 3 › заливка [ ][copy] ↵ [save] ^S [both] ⇧↵ [ocr] ^O 1-9 цвет [ ] толщина ^Z отмена
  • инструменты: прямоугольник и эллипс (f — с заливкой), линия, стрелка, карандаш, маркер, текст, нумерованные шаги, размытие, пиксели;
  • цвет — 1…9, толщина — [ ] или колёсико, отмена — Ctrl+Z / ⌫, повтор — Ctrl+Y;
  • ручки по краям меняют область — нарисованное остаётся на месте;
  • ↵ — копировать (или сохранить — настраивается), Ctrl+C — копировать, Ctrl+S — сохранить в ~/Pictures/Screenshots, Shift+↵ — и то и другое; снимок — в родном разрешении экрана;
  • Ctrl+O — распознать текст в области и положить в буфер (tesseract, английский и русский); Mod+Shift+T — то же сразу: выделили — текст в буфере;
  • i или Mod+Shift+C — пипетка: кликните по точке экрана, цвет #rrggbb — в буфере.

Папка, действие ↵ и уведомление — system/ → скриншоты. Клавиши инструментов работают в любой раскладке. Разметить готовую картинку: qs ipc call shot edit ~/картинка.png.

По мотивам rishot (MIT).

~/docs/clipboard

Буфер обмена

Mod+Shift+V: история всего, что копировали, — текст и картинки, новые сверху. Слева список с нечётким поиском, справа выбранная запись целиком.

  • ↵ или клик — положить запись в буфер, дальше вставляйте как обычно (Ctrl+V, в терминале Ctrl+Shift+V);
  • Del / Ctrl+D — удалить запись, Shift+Del — очистить всю историю (спросит y).

Историю хранит cliphist, пишет её сам shell, пока запущен. Пароли из менеджеров паролей (KeePassXC и другие помечают их) не сохраняются.

~/docs/themes

Темы

look/ → тема: Gruvbox, Catppuccin, Rosé Pine, Tokyo Night, Everforest, Kanagawa, Solarized, Nord или Dracula; в списке рядом с названием — полоска её цветов. тёмная или светлая — режим; светлой нет у Nord и Dracula. Переключить режим: плитка «тема» в home → быстро или qs ipc call theme toggle (dark, light, get). Тема меняет сразу shell, рамки niri, терминал (и уже открытые окна), greeter и приложения.

Wallpaper — палитра из текущих обоев сфокусированного экрана: её строит matugen (ставит установщик), обои сменились — сменилась и палитра. Есть тёмный и светлый вариант. Характер палитры — схема из обоев: tonal-spot (спокойная), content и fidelity (ближе к картинке), expressive, fruit-salad, rainbow (ярче), neutral, monochrome. Акцент выбирается как обычно: ochre — главный цвет обоев, остальные — цвета Gruvbox, сдвинутые к нему.

Темы приложений

look/ → темы Qt и GTK: GTK- и Qt-приложения в той же палитре, с тем же акцентом и шрифтом, что и shell, — через adw-gtk3 / libadwaita и qt6ct. Firefox и Chromium берут тёмную или светлую схему через портал. Иконки: у Gruvbox — Gruvbox Plus, у остальных тем — Papirus с папками цвета акцента (тема-надстройка в ~/.local/share/icons/ochre-Papirus-*, без sudo).

btop — тоже: тема ochre с рамками цвета акцента, прямыми углами и фоном терминала (в btop.conf shell ставит color_theme, theme_background и rounded_corners, остальное не трогает).

Уже открытые окна подхватывают изменения после перезапуска приложения; новые — сразу. Свои стили GTK пишите в gtk.css после строки @import "ochre.css";.

~/docs/lock/

Блокировка и greeter

Блокировка (Super+Alt+L, system/ → lock, после бездействия) и greeter для greetd — один и тот же экран в духе getty. Блокировка проверяет пароль через PAM, greeter — через greetd.

ochre 7.x-arch1-1 (tty1) идёт закат… ochre login: user Password: █

Под приглашением — фраза, как motd в консоли: «с возвращением.», «чайник уже поставлен.», «идёт закат…» — каждый раз другая (выключается в lock/). В greeter сначала вводится имя (подставлено последнее), Tab — сессия, F11 / F12 — перезагрузка / выключение.

❯ sudo bash extras/install-greeter.sh   # greeter (git-установка → /usr/local/share/ochre), niri для него, greetd; у пакета — ochre greeter
❯ sudo systemctl restart greetd

Greeter работает под пользователем greeter и не видит вашу домашнюю папку — поэтому сессия копирует настройки и обои в /var/lib/ochre-greeter/<user>/, и greeter выглядит как shell последнего вошедшего. После обновления git-установки greeter переустанавливается отдельно: system/ → обновить greeter; у пакета он обновляется вместе с ним.

~/docs/game

Игровой режим

Mod+Shift+G, кнопка [game] в home или windows/ → игровой режим: niri работает без анимаций, теней и прозрачности неактивных окон, уведомления показываются только критичные (отключается там же — «не беспокоить»). Ваши настройки при этом не меняются: выключили режим — всё как было.

~/docs/notify/

Уведомления

Shell — сам демон уведомлений. Уведомление — запись лога в рамке, уровень виден по цвету: INFO — акцент, ERROR (критичные) — красный, DEBUG (неважные) — серый. Клик — действие, правый клик — закрыть, наведение ставит таймер на паузу.

┌─[ 21:58 INFO Steam ]────────────────┐ │ friend │ │ Ready to play? │ └─────────────────────────────────────┘ ┌─[ 21:59 ERROR ochre ]─────────┐ │ Настройки не прочитаны │ └─────────────────────────────────────┘

Клик по log на панели — история (до 100), правый клик — «не беспокоить» (проходят только критичные). В истории записи одного приложения собраны в группу ▾ Telegram (3), больше трёх — свёрнута. Клавиши: ↑↓ — строка, ↵ — действие (на группе — свернуть), Space ←→ — свернуть и развернуть, Del — убрать запись или всю группу, d — «не беспокоить», Esc — закрыть. Положение, время показа и максимум на экране — в notify/.

Когда микрофон или звук по умолчанию выключается и включается — биндом, мультимедийной клавишей, из pavucontrol или кликом по vol — приходит короткое уведомление «Микрофон выключен» с названием устройства. Такие уведомления не копятся: новое заменяет прошлое и в историю не попадает. Выключить — notify/ → мьют микрофона и звука.

Steam

Steam рисует свои уведомления отдельным окном, и в niri оно оказывается посреди экрана. Плагин Millennium nopox-notify забирает их у Steam до показа и отправляет как обычные уведомления; свои всплывающие окна Steam больше не показывает.

Если Steam выбран в установщике или уже стоит, установщик сам предложит поставить Millennium и плагин, соберёт и включит его. Вручную:

❯ git clone https://github.com/nopoxxx/nopox-notify && cd nopox-notify
❯ bun install && bun run build   # соберёт и положит в ~/.local/share/millennium/plugins/

Затем включите ochre notify в Steam → Millennium → Plugins и перезапустите Steam.

~/docs/update

Обновления

Shell, установленный через git clone, сам раз в несколько часов делает git fetch. Когда вышли новые коммиты, на панели появляется ochre ↑N: клик — список изменений и [обновить] (git pull --ff-only и перезапуск shell). Частота и уведомление — в system/.

Обновления системы — модуль upd или + → update в меню (paru -Syu).

~/docs/ipc

IPC

Всё, что открывается клавишами, можно вызвать командой — для своих биндов и скриптов. У пакета вместо qs ipc — ochre ipc (то же, что qs ipc -p /usr/share/ochre):

❯ qs ipc call launcher toggle     # меню; launcher apps — сразу программы
❯ qs ipc call settings toggle     # настройки; settings open <раздел> — look, input, system…
❯ qs ipc call wallpaper picker    # обои; wallpaper set <путь>, wallpaper fill <fill|fit|stretch>
❯ qs ipc call displays toggle     # мониторы
❯ qs ipc call binds toggle        # бинды
❯ qs ipc call clipboard toggle    # история буфера обмена
❯ qs ipc call home toggle         # меню home; home open, home close
❯ qs ipc call theme toggle        # тёмная ↔ светлая; theme dark, theme light, theme get
❯ qs ipc call record toggle       # запись экрана; record region, record screen, record stop
❯ qs ipc call shot region         # скриншот; shot window — сразу окно, shot edit <путь> — разметить файл
❯ qs ipc call lock lock           # блокировка; lock preview — предпросмотр без пароля
❯ qs ipc call notify dnd          # «не беспокоить»; notify clear — очистить историю, notify hide — убрать всплывающие
❯ qs ipc call timer start "25m чай" # таймер; timer pause, timer stop, timer get
❯ qs ipc call welcome open        # окно первого запуска: клавиши и подсказки
❯ qs ipc call shell reload        # перечитать конфиг shell без перезапуска
❯ qs ipc call game toggle         # игровой режим; game on, game off, game get
❯ qs ipc call errors get          # ошибки shell и niri текстом; errors open, errors clear, errors report
❯ qs ipc call privacy get         # кто слушает микрофон и показывает экран
❯ qs ipc call screentime get      # время за экраном сегодня: всего и по приложениям
❯ qs ipc call settings set shell.accent blue   # любая настройка из Mod+S; "" — по умолчанию, settings get <ключ> — прочитать
~/docs/hooks

Хуки

Свой скрипт на событие shell: исполняемый файл ~/.config/ochre/hooks/<событие>, данные приходят аргументами. Нет файла или он не исполняемый — ничего не происходит. При запуске shell хуки не срабатывают — только на изменения.

файлкогдааргументы
wallpaperсменились обои на мониторе в фокусепуть, монитор
themeсменились акцент, тема или режимцвет акцента #rrggbb, акцент, тема, dark|light
lock, unlockэкран заблокирован, разблокирован—
gameигровой режимon|off
dnd«не беспокоить» (и через игровой режим)on|off
❯ mkdir -p ~/.config/ochre/hooks
❯ printf '#!/bin/sh\nwal -n -i "$1"\n' > ~/.config/ochre/hooks/wallpaper
❯ chmod +x ~/.config/ochre/hooks/wallpaper   # pywal вслед за обоями
~/docs/faq

Вопросы

пропали бинды, которые я вписал в ochre/*.kdl

Эти файлы генерирует shell и перезаписывает при каждом запуске. Задавайте бинды в окне биндов (сохраняются в settings.json) или в своём ~/.config/niri/config.kdl.

пришло «Настройки не прочитаны»

settings.json повреждён. Чтобы не затереть его, shell работает на умолчаниях и ничего не сохраняет. Исправьте JSON (или удалите файл — настройки сбросятся) и перезапустите shell: system/ → перезапустить shell.

как сбросить всё по умолчанию

Удалите ~/.config/ochre/settings.json и перезапустите shell. Отдельное значение — r на нём в настройках.

в трее у программы буква вместо значка

Программы нет в таблице значков. Её можно добавить в TRAY_ICONS в services/settings.js (пришлите PR) или переключить трей на названия: bar/ → трей → names.

как перезапустить shell

❯ while qs kill; do :; done; sleep 2; niri msg action spawn -- qs

Или system/ → перезапустить shell в настройках.

кто спрашивает пароль для pkexec и systemctl

Сам shell: окно ~/polkit/ в стиле [sudo] password for …, вверху — что именно просит права. Вместо него можно вернуть polkit-gnome: system/ → ochre → polkit-агент.

что показывает окно ~/cast/ при демонстрации экрана

Discord, браузер или OBS просят показать экран — shell спрашивает, что именно: монитор или окно, с живым превью (↵ — показать, Esc — отказать). Остановить демонстрацию можно и в приложении, и биндом niri stop-cast. Если shell не запущен, выбор покажет обычный диалог GNOME. Вернуть его насовсем — system/ → ochre → выбор демонстрации экрана.

в углу появилось окно ~/log/errors

Это ошибки: в QML shell (файл:строка от ~/.config/quickshell/) или в конфиге niri — тогда niri работает на прошлой версии конфига. [скопировать] кладёт текст в буфер, а [сообщить] собирает архив логов в ~/Downloads (логи shell и niri, версии, настройки; домашняя папка, имя пользователя и машины заменены) и открывает новый issue с версиями и ошибками — останется описать проблему и перетащить архив. То же без ошибок: system/ → сообщить о проблеме. Исправленная ошибка QML исчезает после перезагрузки shell, ошибка niri — как только конфиг снова загрузится. Закрытое окно появится снова только на новую ошибку; совсем отключить — system/ → ochre → показывать ошибки.

хочу поправить код

Shell — обычный QML и JS в ~/.config/quickshell/.
