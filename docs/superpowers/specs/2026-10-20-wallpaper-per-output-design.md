# Обои на монитор и стол, слайдшоу, день/ночь

Пункт «Приоритет» из TODO: свои обои у каждого монитора или стола, смена по таймеру из папки,
дневной и ночной вариант по закату.

## Решения

- Уровни: все → монитор → стол; более узкий переопределяет более широкий.
- Слайдшоу: значение слота — файл или папка; папка листается по таймеру.
- День/ночь: явный ночной слот; если пуст — ночной вариант рядом с дневным (`foo-night.png`, `папка/night/`);
  если нет и его — дневной.
- Назначение — в пикере (Mod+Shift+W).

## Данные

`~/.local/state/ochre/wallpapers.json`:

```json
{
  "all":        { "day": "/path/a.png", "night": "" },
  "outputs":    { "DP-1": { "day": "/home/u/Pictures/Wallpapers/space", "night": "" } },
  "workspaces": { "DP-1/2": { "day": "/path/b.png" }, "DP-1/chat": { "night": "/path/c.png" } }
}
```

- Ключ стола — `<выход>/<имя>` для именованного стола niri, иначе `<выход>/<idx>`.
- Пустая строка или отсутствующее поле — «не задано».
- Миграция: файла нет, а старый `~/.local/state/ochre/wallpaper` есть — его путь становится `all.day`.
  Старый файл не удаляется (откат на прежнюю версию shell не теряет обои).
- `wallpaper-fill` остаётся как есть — режим заполнения общий.

## Разрешение — `services/wallpaper.js` (.pragma library)

Чистые функции без QML, покрыты `tests/wallpaper.test.mjs`:

- `wsKey(ws)` — ключ стола из объекта niri (`output`, `name`, `idx`).
- `slotFor(state, output, wsKey, night)` → `{ path, level, time }` — уровни от узкого к широкому
  (стол → монитор → все), побеждает первый уровень, где задано хоть что-то. Внутри уровня ночью — его
  `night`, если задан, иначе `day`; днём — только `day` (уровень с одним `night` днём пропускается).
- `nightVariant(path, isDir)` → путь варианта: файл `foo.png` → `foo-night.png`; папка → `папка/night`.
  Существование проверяет вызывающий (QML знает список файлов).
- `isNight(now, sun)` — `sun = {rise, set}` или `null` → 07:00–19:00 день.
- `pick(list, pos, order, seed)` — следующая картинка слайдшоу: `cycle` — по кругу, `random` — случайная,
  не повторяющая текущую.

Если ночью победил `day`, сначала проверяется его ночной вариант по имени (`nightVariant`),
затем используется сам дневной.

## Сервис `Wallpaper`

- `state` — объект из JSON; `assign(target, path)` и `clear(target)`; `target = { level: "all"|"output"|"ws",
  key, time: "day"|"night" }`. Запись — `FileView.setText(JSON.stringify(...))`.
- `night` — `isNight(now, Weather.sun)`, пересчёт таймером раз в минуту.
- Папки: `Process find` по каждой папке, встречающейся в слотах (и её `night/`), кэш `dirs[path] = [файлы]`,
  перечитывается при изменении state и раз в интервал слайдшоу.
- Слайдшоу: `Timer` с интервалом `shell.wallpaper.interval` минут (0 — выкл.); на каждом тике позиция
  каждого экрана сдвигается. Позиции — `pos[output]`, в памяти; у разных экранов разный начальный сдвиг,
  поэтому одна папка на двух экранах показывает разное.
- `imageFor(output, wsKey)` → путь картинки (файл или выбранный из папки), `""` — нет обоев.
- `current` — картинка сфокусированного экрана (для greeter, отметки в пикере, совместимости).
- `set(path)` — как раньше: `all.day`, для IPC и старых вызовов.
- Подмена фирменных под акцент — по всем слотам state.
- Первый запуск (нет ни нового, ни старого файла) — `all.day` = фирменный horizon, как сейчас.

## Показ

- `Background`: `src` = `imageFor(screen.name, wsKey(активный стол этого выхода))`. Смена стола, слайдшоу
  и день/ночь идут через существующий переход.
- `LockScreen`: `WlSessionLockSurface` — `imageFor(screen.name, …)`; предпросмотр — сфокусированный экран.
- `GreeterSync`: копирует `Wallpaper.current`.

## Пикер

- Строка под поиском: `куда: [все] экран DP-1 стол 2 · [день] ночь`.
  - Ctrl+T — цель по кругу (все → экран → стол), экран и стол — сфокусированные.
  - Ctrl+N — день/ночь.
  - Ctrl+Del — сбросить слот текущей цели (наследует уровень выше).
- В локальном списке после фирменных — подпапки `~/Pictures/Wallpapers` (кроме `night`), плитка `▸имя/`,
  превью — первая картинка; плюс сама коллекция `▸все/`.
- Enter — назначить выбранное в текущую цель. Отметка ● — то, что стоит в слоте цели.
- wallhaven: скачанное назначается в текущую цель.
- IPC: `set <path>` — во «все/день» как раньше; `assign <path> <level> <time>` — в сфокусированный экран/стол;
  `next` — следующая картинка слайдшоу на всех экранах.

## Настройки

В разделе «обои»:

- `shell.wallpaper.interval` — int, минуты, 0–240, шаг 5, по умолчанию 30; 0 — не листать.
- `shell.wallpaper.order` — enum `cycle | random`, по умолчанию `random`.

Строки интерфейса — через `I18n.tr` и `lang/en.json`.

## Ошибки

- Битый JSON — читается как пустой state, файл не перезаписывается до первого назначения.
- Папка пуста или исчезла — слот считается незаданным, цепочка идёт дальше.
- Файл исчез — `Background` показывает `Theme.bg0` (как сейчас при ошибке загрузки).
